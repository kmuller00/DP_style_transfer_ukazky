# DP_style_transfer_ukazky

Tento repozitář obsahuje vybrané zvukové ukázky vytvořené v rámci diplomové práce **Převod řečového stylu v syntéze řeči**.

Ukázky slouží k demonstraci experimentů zaměřených na převod prozodických vlastností řeči do domény vlakových hlášení při současné snaze o zachování identity cílového řečníka.  
Součástí jsou nahrávky generované různými experimentálními přístupy, zejména metodou kombinace modelů a metodou fine-tuningu s předpočítanými akustickými vektory.


Repozitář je určen pouze jako doplňkový materiál k diplomové práci a slouží pro poslechové porovnání vybraných výsledků.
